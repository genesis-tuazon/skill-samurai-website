---
name: Program-page review attribution
description: How to use Winnipeg-wide Google reviews on individual program location pages
---

Use attributed, unaltered parent review quotes for the concern each program page addresses, but label them as Skill Samurai Winnipeg reviews, not reviews of that specific location unless the reviewer explicitly names it.

**Why:** The existing Google review collection spans Winnipeg classes and predates newer locations. Reusing a quote on a location page should not suggest that reviewer attended that branch.

**How to apply:** When rotating or adding program-page testimonials, compare names and full quotes with the site's review collection or another verified source; retain a visible location-neutral label.
